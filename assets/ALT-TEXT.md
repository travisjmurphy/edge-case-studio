# Edge Case Studio

Logo: A bounded interval with a solid point inside and an open point outside.

Cover: Edge Case Studio. Generate repeatable fixtures from a supported schema and a seed. A sample integer range accepts 1 and 99, and rejects 0 and 100.

Demo: Edge Case Studio sample: the seeded checkout fixture set expects reject for quantity 0, accept for 1, accept for 99, and reject for 100. These are schema expectations, not observed application results.
